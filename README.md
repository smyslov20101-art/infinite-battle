# Infinite Battle

> Мобильная игра в жанре **Tower-defense + merge** с мета-прогрессией. GameMaker Studio 2024, GML. Платформа: Android/iOS (целевая).

Колода из 20 героев, рулетка, сундуки, ежедневные квесты, рейтинг — полноценный игровой цикл с мета-прогрессией и системой повторного входа.

## 🎮 Игровой цикл

```
splash → profile / deck / shop / rating / floors → wave / endless
```

- **Колода** — собираешь отряд из 20 героев разных классов (берсерк, паладин, лучник, маг, танк, теневой клинок, и др.). Каждый — со своим on-hit эффектом.
- **Магазин** — рулетка героев, набор карт, сундуки. Все три с авто-обновлением раз в N часов + дополнительные заряды через рекламу (3/день, сброс в полночь МСК).
- **Бой** — TD-арена, герои стоят на позициях, враги идут волнами. Класс-эффекты срабатывают при попадании, не зависят от состояния (idle/fighting).
- **Меta** — гены (синяя валюта) и кристаллы (премиум) копятся; ежедневные квесты дают бонусы; рейтинг между игроками.

## 🏗️ Архитектурные изюминки

**Единый источник правды для сохранений.** Всё игровое состояние в одном объекте `global.permanent_save`. Раньше было три глобала-дубликата (`global.shop_cards_data`, `global.spin_cooldown_data`, `global.ad_data`) — их выпилил, история этого рефакторинга описана в [ARCHITECTURE.md](ARCHITECTURE.md).

**Атомарная запись на диск** (`.tmp` → rename → `.bak`). На любом шаге **минимум один валидный файл существует** — игрок не теряет прогресс при крашe в момент сохранения.

**Время — только Unix-timestamps.** `current_time` возвращает session-local миллисекунды и обнуляется при перезапуске — был баг «20 сек → 38 сек». Все таймеры (рулетка, сундуки, реклама) переведены на `scr_get_unix_timestamp()`, который идёт даже когда игра закрыта.

**`DEBUG_BUILD` макрос для release-сборки.** ~1000 вызовов `show_debug_message` обёрнуты в `LOG` / `LOG_CAT`. Компилятор GameMaker полностью **выпиливает** код при `DEBUG_BUILD = false` — нет накладных расходов на склейку строк в проде.

**`IS_BACK_PRESSED`** — единая абстракция для кнопки «назад»: `vk_escape` (ПК + аппаратная кнопка Android, маппится автоматически) + правый клик мышью. В коде нигде нет прямой проверки клавиш — только макрос.

**Class-effects через `scr_apply_class_onhit`** — единая точка для всех классовых on-hit эффектов. Вызывается И из `STATE_IDLE`, И из `STATE_FIGHTING` (раньше эффекты ближнего боя почти не срабатывали, т.к. герой бьёт чаще из IDLE чем из FIGHTING).

Подробности и история багов — в **[ARCHITECTURE.md](ARCHITECTURE.md)**.

## 🚀 Как открыть проект

1. Установить **GameMaker Studio 2** (2024.14+).
2. `File → Open → final.yyp`
3. `F5` — запуск (Windows-сборка).

Для сборки под Android нужны: Android Studio + SDK + JDK + установленные сертификаты подписи. Конфигурация мобильных целей ещё не настроена (см. бэклог в [ARCHITECTURE.md](ARCHITECTURE.md)).
